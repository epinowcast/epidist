# Is a family the non-parametric hazard family?

Is a family the non-parametric hazard family?

## Usage

``` r
.is_nonparametric(family)
```

## Arguments

- family:

  A family object, or a list recording a delay family as returned by
  [`.delay_family()`](https://epidist.epinowcast.org/reference/dot-delay_family.md).

## Value

A logical scalar.
