# The parameter name `epidist` uses for a parameter type `epireview` names

The parameter name `epidist` uses for a parameter type `epireview` names

## Usage

``` r
.epireview_parameter_name(type)
```

## Arguments

- type:

  A character vector of `epireview` parameter types.

## Value

A character vector of parameter names, `NA` where the type is not
recognised. A mean is `"mean"` and a standard deviation `"sd"`, which
are the moments a fit is often recorded by rather than natural
parameters.
