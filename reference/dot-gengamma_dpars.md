# The Stacy parameters of a `brms` prep object for [`gengamma()`](https://epidist.epinowcast.org/reference/gengamma.md)

The Stacy parameters of a `brms` prep object for
[`gengamma()`](https://epidist.epinowcast.org/reference/gengamma.md)

## Usage

``` r
.gengamma_dpars(prep, i = NULL)
```

## Arguments

- prep:

  A `brms` prep object.

- i:

  The observation index, or `NULL` for every observation.

## Value

A named list of `shape`, `scale` and `k`.
