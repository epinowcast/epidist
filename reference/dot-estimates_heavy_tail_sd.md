# Studies whose reported standard deviation has a heavy tailed sampling error

The studies flagged by
[`.estimates_heavy_tail_rows()`](https://epidist.epinowcast.org/reference/dot-estimates_heavy_tail_rows.md).

## Usage

``` r
.estimates_heavy_tail_sd(data)
```

## Arguments

- data:

  An `epidist_estimates_data` object.

## Value

A character vector of study identifiers.
