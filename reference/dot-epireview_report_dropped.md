# Message about the `epireview` records that were dropped

Message about the `epireview` records that were dropped

## Usage

``` r
.epireview_report_dropped(studies, reason)
```

## Arguments

- studies:

  A character vector naming the study of each record.

- reason:

  A character vector giving the reason each record was dropped, `NA` for
  a record that was kept.

## Value

`NULL`, invisibly, called for the message it may raise.
