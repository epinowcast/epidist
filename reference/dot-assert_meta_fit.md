# Check that a fit is a meta model fitted with `epidist()`

Check that a fit is a meta model fitted with
[`epidist()`](https://epidist.epinowcast.org/reference/epidist.md)

## Usage

``` r
.assert_meta_fit(fit)
```

## Arguments

- fit:

  A meta model fitted with
  [`epidist()`](https://epidist.epinowcast.org/reference/epidist.md) to
  an `epidist_meta_model` object.

## Value

`NULL`, invisibly.
