# The slots of the base estimand a midpoint code is built on

Replaces the censoring adjustment code by the code it is built on and
moves the left truncation point with it. See
[`.meta_cens_base()`](https://epidist.epinowcast.org/reference/dot-meta_cens_base.md)
and
[`.meta_cens_lower()`](https://epidist.epinowcast.org/reference/dot-meta_cens_lower.md).

## Usage

``` r
.meta_cens_slots(slots)
```

## Arguments

- slots:

  The output of
  [`.meta_row_slots()`](https://epidist.epinowcast.org/reference/dot-meta_row_slots.md).

## Value

The slots of the base estimand.
