# Studies reporting quantiles on a coarse delay grid

The studies flagged by
[`.estimates_coarse_rows()`](https://epidist.epinowcast.org/reference/dot-estimates_coarse_rows.md).

## Usage

``` r
.estimates_coarse_quantiles(data)
```

## Arguments

- data:

  An `epidist_estimates_data` object.

## Value

A character vector of study identifiers reporting quantiles on a coarse
grid.
