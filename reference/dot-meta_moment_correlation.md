# The correlation between a reported mean and a reported standard deviation

The correlation between a reported mean and a reported standard
deviation

## Usage

``` r
.meta_moment_correlation(moments)
```

## Arguments

- moments:

  A summary vector from
  [`.meta_moment_vector()`](https://epidist.epinowcast.org/reference/dot-meta_moment_vector.md).

## Value

A correlation strictly inside \\\[-1, 1\]\\.
