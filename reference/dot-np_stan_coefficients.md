# The Stan expression of the hazard coefficients

The Stan expression of the hazard coefficients

## Usage

``` r
.np_stan_coefficients(coefs)
```

## Arguments

- coefs:

  The `coefficients` element of
  [`.np_basis()`](https://epidist.epinowcast.org/reference/dot-np_basis.md).

## Value

A character string holding a Stan vector expression.
