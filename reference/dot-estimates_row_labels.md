# Label flagged summary rows by study and position in the input

Label flagged summary rows by study and position in the input

## Usage

``` r
.estimates_row_labels(data, rows)
```

## Arguments

- data:

  An `epidist_estimates_data` object.

- rows:

  A logical vector selecting the rows to label.

## Value

A character vector such as `"A" (row 2)`, one entry per selected row.
