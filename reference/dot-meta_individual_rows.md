# Build the individual level rows of an `epidist_meta_model` object

Build the individual level rows of an `epidist_meta_model` object

## Usage

``` r
.meta_individual_rows(data)
```

## Arguments

- data:

  Individual level data prepared by
  [`.prepare_marginal_data()`](https://epidist.epinowcast.org/reference/dot-prepare_marginal_data.md).

## Value

A tibble of individual level rows using the meta model slots.
