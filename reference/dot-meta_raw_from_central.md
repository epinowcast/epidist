# The first four raw moments of a set of summaries

Inverts
[`.meta_central_from_raw()`](https://epidist.epinowcast.org/reference/dot-meta_central_from_raw.md).

## Usage

``` r
.meta_raw_from_central(moments)
```

## Arguments

- moments:

  A summary vector from
  [`.meta_moment_vector()`](https://epidist.epinowcast.org/reference/dot-meta_moment_vector.md).

## Value

A numeric vector of the first four raw moments.
