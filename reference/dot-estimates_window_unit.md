# The unit the advisory messages count a study's censoring windows in

The unit the advisory messages count a study's censoring windows in

## Usage

``` r
.estimates_window_unit(swindow)
```

## Arguments

- swindow:

  The secondary censoring windows of the flagged rows.

## Value

`"days"` for daily windows, `"weeks"` for weekly ones, and
`"censoring windows"` otherwise.
