# Check the shared study metadata passed to `epidist_estimates_epireview()`

Check the shared study metadata passed to
[`epidist_estimates_epireview()`](https://epidist.epinowcast.org/reference/epidist_estimates_epireview.md)

## Usage

``` r
.epireview_shared_metadata(...)
```

## Arguments

- ...:

  Study metadata applied to every record.

## Value

A named list with one value per metadata column given.
