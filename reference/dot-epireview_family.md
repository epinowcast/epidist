# The family `epidist` calls a distribution `epireview` names

The family `epidist` calls a distribution `epireview` names

## Usage

``` r
.epireview_family(type)
```

## Arguments

- type:

  A character vector of `epireview` distribution types.

## Value

A character vector of families, `NA` where the family is not one
[`epidist_estimates_parameters()`](https://epidist.epinowcast.org/reference/epidist_estimates_parameters.md)
supports.
